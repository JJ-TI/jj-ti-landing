# Solicitar información

Selecciona un plan o pide ayuda para elegir. Completa tus datos de contacto, marca al menos una necesidad, describe el problema y lee el aviso de privacidad. No compartas contraseñas, certificados ni datos financieros.

Al aceptar el envío, el servicio muestra una referencia para consultar con JJ-TI; no significa que exista un contrato ni una garantía de entrega al correo. Si aparece un error, tus datos permanecen en la página. Comprueba antes de reintentar para evitar duplicados o usa info@jj-ti.net y WhatsApp.

Sin JavaScript se usa el formulario nativo del proveedor: selecciona el plan manualmente y completa su verificación. Indica la necesidad también en el mensaje.
